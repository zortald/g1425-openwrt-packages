OpenWrt package feed for Nokia G-1425-MA

Kernel modules and target packages for the custom OpenWrt build on the Nokia G-1425-MA ONT (EcoNet EN7526GT / EN751221). downloads.openwrt.org does not build the econet target.

Kernel modules only install on the exact kernel they were built with, so there is one folder per kernel build. The firmware adds its folder to apk at first boot:

https://zortald.github.io/g1425-openwrt-packages/<kernel-hash>/packages.adb
